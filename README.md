# פינקלשטיין נוסעים ללונדון

אפליקציית ליווי לטיול המשפחתי ללונדון, 15–27 בספטמבר 2026.

## הרצה מקומית

```bash
npm install
npm run dev
```

הפקודה תפתח שרת פיתוח מקומי (Vite) — פותחים את הכתובת שמודפסת בטרמינל בדפדפן.

## בנייה לפרודקשן

```bash
npm run build
npm run preview   # לבדוק את הבילד המוכן לפני פריסה
```

תוצר הבנייה נכתב לתיקיית `dist/` — כל שירות אחסון סטטי (Vercel, Netlify, GitHub Pages וכו') יכול לשרת אותה.

## התקנה על מסך הבית באייפון (PWA)

1. פותחים את כתובת האפליקציה בספארי באייפון.
2. לוחצים על כפתור השיתוף (הריבוע עם החץ).
3. בוחרים "הוסף למסך הבית" (Add to Home Screen).

האפליקציה תיפתח במסך מלא בלי סרגלי דפדפן, עם האייקון והשם שהוגדרו.

## מבנה הפרויקט

- `src/FinkelsteinLondonApp.jsx` — כל לוגיקת האפליקציה והעיצוב (עיצוב "פוסטר טיולים רטרו בריטי").
- `src/data/places.js` — רשימת האטרקציות והמסעדות. זהו קובץ הנתונים היחיד שצריך לערוך כדי לעדכן דירוגים, להוסיף מקומות חדשים או לתקן קואורדינטות — שאר הקוד לא צריך להשתנות.
- `public/manifest.webmanifest`, `public/icons/` — קבצי ה-PWA.

## שמירת מידע

התוכנית היומית (`itinerary`) נשמרת ב-`localStorage` של הדפדפן/המכשיר — היא נטענת אוטומטית באתחול האפליקציה ונשמרת בכל שינוי. המידע נשאר על המכשיר הספציפי שבו נעשה שימוש (אין סנכרון בין מכשירים).

## מקורות נתונים חיצוניים (ללא צורך במפתח API)

- מזג אוויר: [Open-Meteo](https://open-meteo.com/)
- גיאוקודינג (הזנת מיקום ידנית ב"קרוב אליי"): [Nominatim](https://nominatim.openstreetmap.org/) (OpenStreetMap)
